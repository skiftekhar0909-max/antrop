# anthrop Architecture Studio

Official portfolio website for anthrop, a multidisciplinary architecture and
design practice based in Bhubaneswar, Odisha.

## Services

- Architectural planning
- Interior architecture
- Landscape architecture

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Production

```bash
npm run build
npm run start
```

The project uses Next.js, React, TypeScript and Tailwind CSS.
